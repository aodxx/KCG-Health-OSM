## Why v0.1 Was Retired

v0.1 ถูกเขียนก่อนการตกลง Product Definition ใหม่ และเคยใช้ journey แบบ:

`Assign → Visit → Observation → Risk → Review → Referral → Follow-up → Close`

รวมทั้งเคยกำหนด NCD/home-visit เป็น MVP core และวาง Supabase ไว้ใน phase ต้น ๆ

แนวทางดังกล่าว **ไม่ใช่ Product Core ปัจจุบันแล้ว**

Product Core ที่ใช้อยู่คือ:

`Create Form → Define Audience → Publish → Route to Citizen/Volunteer → Complete → Submit → Review → Follow-up/Referral → Export-ready`
